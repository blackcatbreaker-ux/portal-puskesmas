Panduan Deploy ke GitHub Pages

Aplikasi E-Portal Puskesmas ini telah dirancang Single-File Production Ready. Anda dapat mempublikasikannya secara online dan gratis via GitHub Pages dengan langkah berikut:

  1. Buat repository baru di GitHub (misal: eportal-puskesmas).
  2. Simpan seluruh kode file ini dengan nama index.html.
  3. Upload/Push file index.html ke branch utama (main) di repository Anda.
  4. Buka menu Settings → Pages pada repository GitHub Anda.
  5. Pada opsi Source, pilih branch main / root folder, lalu klik Save.
  6. Aplikasi E-Portal Puskesmas Anda akan aktif dalam beberapa menit di URL https://username.github.io/eportal-puskesmas!
